# Mysterio Sky Probe

A single-page Meta Ray-Ban Display web app that measures glasses orientation (`DeviceOrientationEvent`), gyro rate, sensor-fusion lag and heading accuracy for world-locked sky overlays. It shows a world-locked horizon, cardinal points, a pinnable direction and the computed sun position.

Nothing is sent anywhere: sensor and location readings stay on the device. `?demo=1` simulates sensors in a desktop browser.
